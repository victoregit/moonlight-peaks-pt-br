🇧🇷 **Tradução para Português Brasileiro** – Traduz o jogo para PT-BR

## 🛠️ Instalação

1. Baixe a versão mais recente da tradução.
2. Extraia os arquivos.
3. Coloque a pasta `BepInEx` no diretório de instalação do *Moonlight Peaks*.
4. Inicie o jogo.
5. A tradução será aplicada automaticamente.

## 📝 Notas

- A tradução é aplicada automaticamente.
- Nenhum arquivo original do jogo é modificado.
- Para retornar ao idioma original, remova os arquivos da tradução.
